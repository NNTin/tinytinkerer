# Using TinyTinkerer

This section is for people who already have access to a running TinyTinkerer instance and want to
use it — chatting, working in the integrated Canvas/IDE/Mermaid/Pixel Agents workspaces, and
configuring plugins and MCP servers from Settings.

## Content gap

Task-oriented "how to use the product" material (a guided tour of the chat surface, the
application workspaces, and Settings) does not exist yet. This is intentional: the [evaluator and
builder learning-path issue](https://github.com/NNTin/tinytinkerer/issues/449) that follows this
information-architecture work is where that walkthrough content will be written, rather than
opportunistically expanding architecture documents here.

## In the meantime

- [Open TinyTinkerer](pathname:///) and explore the product directly.
- [Plugins & Tools](../plugins-and-tools/index.md) documents the tools available to the assistant
  and how MCP servers are registered, which doubles as a reference while using the product.

## Next step

If you want to add a capability rather than just use existing ones, continue to
[Plugins & Tools](../plugins-and-tools/index.md) or [Extending the Content & Runtime](../extending/index.md).
