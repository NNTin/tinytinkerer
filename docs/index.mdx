# TinyTinkerer documentation

TinyTinkerer is a Rube Goldberg machine for human-computer conversation. These documents describe
the product, its architecture, its extension points, and how to run it.

<DocumentationPlatformStatus />

## Start exploring

- [Architecture](./ARCHITECTURE.md) maps the monorepo, layers, and dependency rules.
- [Plugin infrastructure](./plugin-infrastructure.md) explains how optional capabilities join the
  agent runtime.
- [Content platform](./content-platform.md) documents rich assistant-content parsing and rendering.
- [Vercel deployment](./vercel-deployment.md) covers hosting the frontend and edge services.
- [Contributing](./CONTRIBUTING.md) describes contribution and licensing terms.

This landing page is intentionally small. The evaluator and builder information architecture will
be expanded in follow-up documentation issues.
