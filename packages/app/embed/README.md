# @nntin/tinytinkerer-embed

TinyTinkerer's browser chat runtime — `createBrowserApp`, `ChatApp`, app tool groups and the
plugin catalogue — as one prebuilt ESM package with TypeScript declarations, for hosts that embed
the assistant on their own page.

- Peer dependencies: `react` and `react-dom` 19. Nothing else is installed into your tree.
- Stylesheets: `@nntin/tinytinkerer-embed/embed.css` and `@nntin/tinytinkerer-embed/styles.css`.
- Published to GitHub Packages (`https://npm.pkg.github.com`), which requires a token with
  `read:packages` even for reads.

Install, configuration and a minimal host:
[Embedding TinyTinkerer in another app](https://tiny.nntin.xyz/docs/extending/embed-package).
